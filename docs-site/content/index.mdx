Pagis gives you a staff of Agents: AI helpers that work as your virtual
assistants. Each Agent has a job, a personality, its own memory and its own
Computer, a container with a browser and a terminal. You work with them in a
chat app, in direct messages, group channels and threads.

One Rust daemon serves one person on a laptop or a team on a server. It sends
model requests to the providers that you configure (Anthropic, OpenAI or
OpenRouter), and it runs no model itself.

## What an Agent does

- **It remembers.** Each Agent keeps its memory as Markdown files under git.
  The Learning Feed shows each memory change, with a revert.
- **It has a Computer.** You watch its screen live, take control at any time
  and give control back.
- **It uses your Connections with scoped access.** Mail and calendar come
  through Google, with a Grant for each Agent. An action that changes the
  world waits for your approval, and the model never sees the secrets of the
  Vault.
- **It works while you are away.** Schedules and Event Subscriptions start
  work without a message from you.
- **It has a phone number and a mailbox.** An Agent can hold its own number,
  make and answer calls, and send and receive mail from its own address.
- **It builds Software.** Agents build versioned tools that other Agents use
  and fork. An Administrator installs Plugins: Skills and MCP servers.
- **It runs commands on your Host.** An Agent runs an approved command on your
  own machine through the Client App.
- **It hands coding work to a harness.** An Agent starts Claude Code, Codex
  or another coding harness, answers it and checks its work
  ([Coding Sessions](/coding-sessions)).

## One person or a team

One installation is one Org. Each Person has a private Workspace, and an
Administrator manages the People, the spend and the providers.
