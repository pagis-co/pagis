The Headless Server is the Pagis server as a Linux container image. A team
runs it on its own VM. The Compose deployment runs the server image, Postgres,
a Caddy proxy that holds the TLS certificate, and the egress rules of the
Computers.

## Prerequisites

- A Linux VM with Docker and Docker Compose.
- A domain name that points to the VM.

## Start the server

Replace `<release>` with the release that you install, for example `0.1.0`.

```bash title="Terminal"
git clone --depth 1 --branch v<release> https://github.com/pagis-co/pagis
cd pagis/deploy
mkdir -p secrets
head -c 32 /dev/urandom | od -An -tx1 | tr -d ' \n' > secrets/pagis-secrets-key
chmod 600 secrets/pagis-secrets-key
cp .env.example .env    # set the domain, the public address and the passwords
docker compose up -d
```

## Set the first Administrator

A new server has nobody who can sign in. Make the first Administrator in one
of two ways.

<Tabs items={['From the environment', 'From a browser']}>
  <Tab value="From the environment">
    Before the first start, set `PAGIS_ADMIN_EMAIL`, `PAGIS_ADMIN_PASSWORD`
    (at least 12 characters) and the key of each model provider in `.env`.
    The daemon reads them at the first start.
  </Tab>
  <Tab value="From a browser">
    Leave the variables empty. The Administration Port binds loopback, so open
    an SSH tunnel to it:

    ```bash title="Terminal"
    ssh -L 4401:127.0.0.1:4401 pagis.example.net
    ```

    Then open `http://127.0.0.1:4401/` and complete the Server Setup.
  </Tab>
</Tabs>
